# Bata vs Brands 👟

A footwear comparison website created to explore and compare Bata footwear with products from other popular footwear brands.

## About

Bata vs Brands is a front-end web project designed to help users explore different footwear options and understand the differences between Bata and other brands.

The website presents footwear information in a simple and visually engaging format, making it easier to browse products and compare available options.

## Features

- 👟 Footwear product showcase
- 🔎 Brand and product comparison
- 🏷️ Product and brand information
- 📱 Responsive web design
- 🎨 Interactive and user-friendly interface
- 🌐 Web-based platform accessible through a browser

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Purpose

This project was created as a web development project to practice and demonstrate front-end development skills, including:

- Web page structure
- Styling and responsive layouts
- JavaScript interactions
- User interface design
- Product presentation
